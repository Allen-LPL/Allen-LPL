# How to publish this profile README

Your GitHub **profile README** must live in a repo named **exactly** after your
username: `Allen-LPL/Allen-LPL`. GitHub then renders `README.md` at the top of
<https://github.com/Allen-LPL>.

This folder is already a local git repo. Steps:

## 1. Create the repo on GitHub

Either via the web UI (New repository → name it `Allen-LPL`, **Public**, do NOT
add a README/license), or with the `gh` CLI:

```bash
gh auth login              # one-time, if not logged in
gh repo create Allen-LPL --public --source=. --remote=origin --push
```

If you used the web UI instead, wire up the remote and push manually:

```bash
cd ~/Code/Allen-LPL
git add .
git commit -m "profile: dark engineering README with stats, projects, AI stack"
git branch -M main
git remote add origin git@github.com:Allen-LPL/Allen-LPL.git   # or https://
git push -u origin main
```

## 2. Turn on the contribution snake (one-time)

The 🐍 snake image is generated by the included Action
(`.github/workflows/snake.yml`) into an `output` branch.

1. After the first push, open the repo → **Actions** tab → enable workflows.
2. Run **"Generate contribution snake"** manually (Run workflow) — or just wait
   for the 12-hour schedule.
3. It creates the `output` branch with the SVGs the README points to.
4. Settings → Actions → General → Workflow permissions → ensure **Read and write
   permissions** is enabled (needed to push the `output` branch).

Until that first run finishes, the snake image will 404 — that's expected; every
other widget works immediately.

## 3. Verify

Open <https://github.com/Allen-LPL> — the README renders above your pinned repos.
The stats / streak / trophy / typing cards are live third-party SVGs and update
on their own.

## 4. (Recommended) Self-host the two flaky widgets

Two widgets in the README use community-hosted instances that are frequently
rate-limited / over-quota:

- **Stats card + Top languages** → `github-readme-stats.vercel.app` (often `503`)
- **Trophy** → `github-profile-trophy.vercel.app` (often `402`)

They render only when those shared instances happen to be up. For a profile that
never shows broken images, deploy your own copies (free) and swap the host in
`README.md`.

**github-readme-stats (stats + top-langs):**

1. Fork <https://github.com/anuraghazra/github-readme-stats>.
2. Create a GitHub **Personal Access Token** (classic, no scopes needed for public
   stats; add `repo` if you want `count_private=true`).
3. Import the fork into <https://vercel.com>, add env var `PAT_1 = <your token>`,
   deploy. You get e.g. `https://grs-allen.vercel.app`.
4. In `README.md`, replace both `github-readme-stats.vercel.app` occurrences with
   your domain. All the `*_color` / `bg_color` params carry over unchanged.

**github-profile-trophy:**

1. Fork <https://github.com/ryo-ma/github-profile-trophy>, deploy to Vercel the
   same way (env var `GITHUB_TOKEN = <your token>`).
2. Replace `github-profile-trophy.vercel.app` in `README.md` with your domain.

> Alternatively, just delete the "GitHub Stats" stats/top-langs images and/or the
> trophy line — the streak card, typing banner, skill icons and visitor counter
> all work off reliable hosts and need no setup.

### Notes

- **Payment screenshots were intentionally left out.** A profile is fully public;
  embedding subscription/transaction images would leak financial + account data.
  The AI stack is shown as badges instead.
- All widget colors are matched to your cv site (navy `#0e1524`, cyan `#38bdf8`,
  amber `#f5b451`). To retheme, edit the `*_color` / `bg_color` query params in
  the image URLs.
